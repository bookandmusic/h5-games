# 星图：平行位面 — 设计系统

> 暗色宇宙 + 全息星图 + 3D 星魂图标 手游设计系统

## 1. 视觉氛围

- **深色宇宙**：主背景 `#071126`，深空面板 `#101B3D`
- **全息星图**：连线 `#35E6FF`，星轨描边，蓝紫金点缀
- **3D 星魂图标**：pop mart + pixar 风格，二次元卡通渲染，精致光影
- **平行位面裂隙**：困难模式红蓝裂隙闪烁

## 4. 组件规范

### 4.0 统一组件类

所有界面必须优先使用 `game-theme.css` 中的 `star-*` 组件类，页面内 scoped CSS 只负责页面专属布局和少量状态覆盖。

| 类名 | 用途 | 约束 |
| --- | --- | --- |
| `.star-page` / `.star-play` | 页面根容器 | 占满 `GameContainer`，不额外处理 safe area |
| `.star-top-hud` | 顶部 HUD | 高度 ≥ 56px，半透明深空面板，资源/返回/标题统一容器 |
| `.star-hit-icon` | 透明图标热区 | 点击区 ≥ 48px，只显示图标本体，不显示方框按钮 |
| `.star-hud-value` | HUD 数值 | 体力、星券、收集进度统一使用，不使用圆角胶囊 |
| `.star-hud-meter` | 局内统计刻度 | 步数、配对等局内统计使用细线刻度，不使用卡片 |
| `.star-panel` / `.star-modal` | 面板/弹窗 | 深空渐变 + 全息描边 + 蓝色微光 |
| `.star-rune-tab` | 符文标签/筛选 | 位面切换、稀有度筛选、状态筛选统一使用，禁止做成网页 chip |
| `.star-card` | 角色卡/盲盒卡 | 深色半透明卡面 + 底部厚阴影 + 按下回弹，禁止用于普通统计数字 |
| `.star-primary-btn` | 主按钮 | 蓝色全息 3D 按钮，底部厚阴影 |
| `.star-secondary-btn` | 次按钮 | 深空半透明按钮，蓝色描边 |

### 4.1 3D 按钮 (`.btn-3d`)

- 视觉高度: 48-56px，点击区 ≥ 48px
- 金色变体 (`.btn-3d-gold`): 星辉蓝渐变 + 6px 底部阴影
- 幽灵变体 (`.btn-3d-ghost`): 半透明 + 蓝色描边
- 按下态: `scale(0.94) translateY(2px)`

### 4.2 图标热区 (`.star-hit-icon`)

- 触控热区: ≥ 48×48px
- 视觉尺寸: 图标本体 32-42px
- 视觉: 透明背景，不显示方框、不显示厚边框
- 仅返回、关闭、菜单允许使用轻微发光或阴影，不允许变成独立方形按钮
- 按下态: `scale(0.9)` + 提亮

### 4.3 资源仪表 (首页顶部)

- 高度 ≥ 40px
- 图标 + 数值 + 细线进度，不使用圆角胶囊外框
- 体力：星核晶体图标 + 能量槽进度
- 星券：发光票据图标 + 计数
- 收集：星魂档案图标 + 进度

### 4.4 星球节点 (星图页)

- 3D 星球图标 80-110px
- 外圈发光光晕
- 四级状态（见 §5）
- 点击区 ≥ 80px

### 4.5 角色档案卡

- 宽高比 2:3
- 3D 卡片效果 (底部阴影)
- 稀有度角标: 右上/左上 22-28px 徽章，非整条横幅

### 4.6 盲盒胶囊

- 3D 星匣/胶囊外观
- 6 张 3×2 网格
- 选择态: 金色边框 + 发光

### 4.7 弹窗

- 深色面板 + 蓝色描边
- 圆角 20-24px
- 标题星券金
- 不使用系统弹窗

## 5. 状态规范

| 状态 | 视觉表现 |
| --- | --- |
| **默认** | 正常显示 |
| **按下** | `scale(0.92-0.94)` + `translateY` |
| **禁用** | `opacity: 0.3-0.55` / 灰显 + 无 pointer-events |
| **选中** | 金色边框 + 发光 |
| **可领取** | 脉冲动画 + 金色描边 |
| **已领取** | 低亮度完成印记 |
| **锁定** | 暗色剪影 + 封印锁 + 无 pointer-events |
| **加载** | 不使用静态"加载中..."，用微光动画 |

**星球四级状态**（§6.3）：

| 状态 | 条件 | 表现 | 可点击 |
| --- | --- | --- | --- |
| 未解锁 | 前置条件未达成 | 暗色剪影、封印锁、低亮度 | 否 |
| 可唤醒 | 前置达成未进入 | 外圈脉冲、"可调律" | 是 |
| 调律中 | 已进入且 ≥1 角色 | 正常发光、进度环 | 是 |
| 完成 | 18/18 收集 | 金色星轨环、完成印记 | 是 |

**角色画廊状态**（§6.5）：

| 状态 | 条件 | 表现 | 操作 |
| --- | --- | --- | --- |
| 未解锁 | 未获得 | 剪影/模糊、封印纹路 | 查看线索 |
| 可兑换 | 未获得 + 星券足够 | 剪影亮边、兑换按钮 | 星券兑换 |
| 已解锁 | 已获得 | 完整立绘、名称、稀有度 | 查看详情 |
| 新获得 | 刚解锁 | NEW 标记、星光动画 | 查看详情 |

## 6. 布局规范

- **网格**: 8px 基础网格
- **安全区**: 由 GameContainer 提供，游戏内不重复处理
- **拇指热区**: 底部 40% 区域为主要交互区
- **Container Queries**: 游戏内所有布局适配使用 Container Queries，禁止 `@media`
- **宽高比**: 默认 3:4 (GameContainer)，局内保持
- **最小触控**: 48px (图标按钮)，56px (主操作)，72px (模式入口)
- **页面统一骨架**: 顶部 `star-top-hud` 放资源/返回/标题，中部放核心内容，底部放主操作或局内道具按钮
- **页面范围**: 首页、星图、星魂画廊、兑换舱、局内、调律弹窗、结果弹窗、盲盒弹窗全部遵循同一套 `star-*` 组件语言

## 7. 禁忌项

- ❌ 不使用纯黑 `#000`
- ❌ 不使用大面积纯白
- ❌ 不使用渐变文字 (`-webkit-background-clip: text`) 作为主标题
- ❌ 不使用简单方块按钮作为主要交互
- ❌ 不使用系统 `alert/confirm/prompt`
- ❌ 不使用静态"加载中..."
- ❌ 不依赖 `:hover` 效果
- ❌ 稀有度不使用整条顶部横幅，统一改为角标
- ❌ 不使用 `@media` 做游戏内布局适配
- ❌ 动画不直接操作 `offsetTop`/`scrollTop`

## 8. 动画规范

- 过渡时间: 0.12-0.25s
- 缓动: `ease` / `cubic-bezier(0.34, 1.56, 0.64, 1)` (弹性)
- 卡片翻转: CSS 3D transforms + `will-change: transform`
- 配对成功: 淡出动画 (`transform` + `opacity`)
- 尊重 `prefers-reduced-motion: reduce`
