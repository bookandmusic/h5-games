## 一、统一风格基线

### 1.1 视觉关键词

- 暖暖系、少女向、精致、轻甜、梦幻、时装感
- 奶油白、蜜桃粉、香槟金、珠光白、柔雾玫瑰、浅杏、暖灰蓝
- 3D 厚涂渲染、柔和高光与渐变阴影、轻微投影、立体浮雕感、爱心/蝴蝶结/珍珠/花瓣/宝石细节
- 干净发光、层次细腻、适合叠 UI，不做厚重写实或通用二次元插画风

### 1.2 图标参考风格

参考你提供的示例图标（icon-resource-exp.png）：

- 3D 厚涂渲染质感，非平面珐琅/搪瓷
- 奶油白主色块 + 明显的金色立体包边 + 蜜桃粉蝴蝶结/装饰
- 柔亮高光 + 渐变阴影 + 轻微投影（drop shadow），立体浮雕感强
- 点缀色：绿色/金色星形/ sparkle 装饰
- 单体主体居中、透明背景、强识别度
- 整体像高质量中式少女生活模拟手游 icon，通透有光泽

### 1.2.1 全局提示词后缀

**所有提示词在末尾统一追加以下后缀，确保渲染风格一致：**

```
glossy 3D rendered life simulation mobile game icon style, soft gradient shading, subtle drop shadow, cream white and blush pink primary palette with champagne gold trim, transparent background
```

背景图（backgrounds/）除外，使用以下后缀：

```
glossy 3D rendered life simulation mobile game art style, soft gradient shading, dreamy layered composition, cream white and blush pink primary palette with champagne gold ambient lighting
```

事件图（events/）使用以下后缀：

```
glossy 3D rendered life simulation mobile game story card style, same heroine character design throughout, soft gradient shading, cinematic pastel lighting, cream white and blush pink primary palette with champagne gold ambient glow
```

角色立绘（skins/）使用以下后缀：

```
glossy 3D rendered life simulation mobile game character art style, same heroine face and body proportions throughout, soft gradient shading, subtle rim light, cream white and blush pink primary palette with champagne gold fabric details, transparent background
```

小游戏物件（minigames/）使用以下后缀：

```
glossy 3D rendered life simulation mobile game icon style, soft gradient shading, subtle drop shadow, cream white and blush pink primary palette with champagne gold trim, transparent background
```

### 1.3 全局负面约束

所有资源都尽量避免：

- 写实照片感、校园写真感、普通漫画截图感
- 赛博风、暗黑风、欧美卡通风、商务扁平插画风
- 过深阴影、脏灰色调、荧光高饱和撞色
- 文本、水印、Logo、UI 截图式构图

## 九、事件驱动的角色立绘设计

说明：

- 第 9 章不再按“现有 skin 文件”组织，而是按 **当前游戏全部关键事件** 重做角色立绘提示词
- 这部分只服务于“事件对应皮肤设计”，不受现有资源数量、旧文件名、旧解锁表约束
- 风格必须继续保持当前游戏口径：**暖暖系、柔和粉金白、精致蝴蝶结与珍珠装饰、甜美都会感、轻奢少女感**
- 只强约束“这是同一位女主”，核心是 **人脸一致、年龄感一致、发型家族与发色一致**
- 姿势、手势、镜头、动作感、职业道具、场景互动允许跟随事件变化
- 如果沿用同一母版站姿，可保持比例接近；如果事件需要新动作，不强制“同姿势同身高”

### 9.1 设计原则

- `highschool` 与 `exam`：偏校园、清透、紧张成长感，制服和学习道具更明显
- `college`：更成熟、轻都会学生气质，层次更丰富，书卷感与舞台感并存
- `work-basic` 与 `adult-exam`：强调现实打拼、通勤、兼职、二次出发，不再只是学生装改色
- `work-study` 与 `work-advanced-*`：突出“职业 + 学习 / 晋升”双重身份，造型要明显升级
- `business` 与 `postgame`：进入经营者与财富自由阶段，服装更精致、更有品牌感与主角高光感
- 所有提示词都默认接在 `3.5.1 Base Pose` 或 `3.5.2 Event Pose` 后使用
